# Training

Persönliche Training & Fueling Webapp.

## Dokumentationsregel

Diese Anwendung dient der Darstellung, Berechnung und Analyse der Trainingsdaten. Projektinhalte, Gesprächsdokumentation und ausführliche Notizen werden nicht automatisch in der Webapp gespiegelt. Nur ausdrücklich für die Webapp bestimmte Daten und Funktionen werden dort hinterlegt.
